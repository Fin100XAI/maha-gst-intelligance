# test-data/ward — synthetic ward SYN-PUNE-01

**Synthetic data. Not real taxpayers, not departmental outcomes.** Every company name ends in `[SYN]`, every PAN
starts with `ZZ`, and the jurisdiction is `SYN-PUNE-01`. Never present these figures as actual Maharashtra GST results.

Generated by `node scripts/synth/ward.mjs` (fixed seed: regenerating writes these files byte for byte, enforced by
`tests/ward.test.mjs`). Transactions are generated ledger-first: an invoice between two ward taxpayers exists once and
appears in the seller's GSTR-1 and the buyer's GSTR-2A/2B.

## Contents

- **46 returns workbooks**: 16 taxpayers × FY 2023-24, 2024-25, 2025-26 (Vista Trading registered in July 2025, so one
  year). Same 29-sheet layout as the portal "Get Download All Report" export. Extract (download) dates:
  20-11-2024, 20-11-2025 and 26-09-2026.
- **`registers/`**: `master.csv` (taxpayer master), `eiu.csv` (7 EIU risk signals), `targets.csv` (36 monthly
  targets), `demands.csv` (6 demands at different stages). Upload from *Data sources → Registers*.
- **`answer-key.json`**: every planted fact, measured from the generated data.
